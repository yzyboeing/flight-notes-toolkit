# 产物类型、表达约定与排版规格

## study 文档与执行速查表

用户说“速查表”“执行清单”“查阅用”，或材料本身是一组判据加一组动作时，做执行速查表。笔记库第 0 章按速查表规则，第 1–4 章按 study 文档规则。

| 项目 | study 文档 | 执行速查表 |
|---|---|---|
| 读者状态 | 坐下来学习 | 正在执行，边看边做 |
| 共性前提 / 末尾补充 | 保留 | 原则上删除；执行必须知道时才保留 |
| 原理、为什么、易混对比 | 保留 | 删除 |
| 原文条款号、(a)(b)(c) | 保留 | 删除，按执行顺序平列 |
| 括号补充 | 原理与背景可保留 | 只保留消歧义内容 |
| 来源行和元说明 | 保留 | 删除 |
| 使用说明 | 可保留 | 删除，结构应自明 |

速查表只保留执行时需要照着做或据以判断的内容。删掉的理解性内容不得丢失，应进入对应 study 文档。标题写主题，不写“study 文档”或“执行速查表”等体裁名称。

## 单元格表达

- 行首不使用 `▪`、`•`、`-`、`*`。层级用换行、缩进和加粗前缀标签表达。
- 连续动作写成单行 `A → B → C`。
- 真正的时序步骤使用独立序号列和 ①②③；父条件下多个子条件按 `structure.md` 处理。
- 原理解释放在动作后括号内；速查表只保留消歧义括号。
- 时间单位用 `3min`、`5min`、`1min` 等缩写。
- 同类并列项用“·”紧凑分隔。
- 项目内机型差异用 `【737-NG】` 或 `【737-8】`；条目级适用性另用 `[NG]` 等标记。
- 检查单名用《》包裹。
- 只加粗结论关键词、前缀标签、判据、限制和关键动作，不整条加粗。
- `≥`、`≤` 可能乱码时改写为“及以上 / 及以下”，不得改变原意。

## 表格尺寸、列宽与对齐

表格长、宽、高必须随内容多少调整，不对所有表格机械套用同一宽度或固定行高。

- **内容密集**：文字总量较大、列较多或自然换行会产生很多行时，表格尽量铺满左右页边距之间的可用版心。在不降低可读性、不压缩字符、不删改内容的前提下，通过加宽表格和合理分配列宽减少无意义换行和总行数。
- **内容较少**：以“最长一行正好能单行容纳”为目标宽度，同时按各列内容量分配列宽，不强制拉满版心。保持紧凑但不拥挤，避免表格内和表格右侧留下大片无意义空白。
- **列宽**：按每列的职责和“最长有意义信息单元”分配，不按原图线比例，也不按整列累计字数机械复制。①②③、序号、是/否、短标签等列压到满足可读性的最窄宽度；首列若是完整的项目名、警告名或状态名，应适当加宽并尽量保持一行。长说明、处置和结果列只有在内容确实需要连续阅读时才优先取得剩余版心；若单元格由多条可自然换行的并列句组成，应按最长并列项估宽，可以适当收窄，不因总字数多而占满页面。
- **行高**：随内容自动展开，不设置制造空白或可能截断文字的固定高度；单元格内边距保持一致。
- **对齐**：以简洁、稳定、横向扫读自然为准，不机械规定只能某一行或某一列居中。表头、序号、数值和短标签可居中；说明性长文、动作流程和条件叙述左对齐。同一列保持一致，实际效果以渲染后视觉复核为准。
- **压缩边界**：不得为了减少行数而缩小到难读的字号、压缩字距、删信息、改技术文字或破坏父子条件层级。
- **验收依据**：以渲染后的实际页面为准，检查异常留白、拥挤、溢出、逐字换行和无意义拆页。

“第 91 页”只是促成本规则的案例，不写入永久规则；所有页面统一按内容自适应原则处理。

## 排版标杆的使用

用户另给 `.docx` 作为排版样本时，先逐页渲染并提取页面、字体、标题、间距、表格、页眉页脚等可验证参数，再迁移其视觉体系。只学习排版，不复制样本文字、编号、章节结构或技术内容。

- 用户已经确认的内容忠实、章节命名、表格自适应宽度和对齐规则优先于样本中的机械做法；例如样本若所有表格都铺满版心，而用户已要求短内容表格收缩，则只继承其字体、底纹、边框、间距等视觉规范。
- 标题必须继续使用 Word 内置 Heading 样式以支持自动目录，即使样本仅用普通段落直接格式化；视觉参数可以复刻，结构语义不得倒退。
- 本轮确认的出版物基线：A4 横版、四边约 12.5 mm；Arial 9.5 pt 正文；11 pt 条目标题，段前 12 pt、段后约 4.5 pt；15 pt 白字深灰章节条；表格单元格上下 60 twips、左右 100 twips，段前段后各约 1.5 pt、约 1.04 倍行距；长说明顶端左对齐，表头和短标签垂直居中。

## 灰阶管结构，红色管重点

全篇只使用灰阶、红色和一个浅蓝灰；不用荧光笔、橙、琥珀、黄或大面积深色块。

红色 `C00000` 是唯一强调色，依次用于：分组判定结论、分支判据、限制值与禁止措辞、关键动作与易错点、系统不可用项。一个单元格通常不超过一处红色；分组结论和该组阈值可以并存。不得整行或整列标红。

| 元素 | 规格 |
|---|---|
| 页面 | A4 横版，窄边距 |
| 页面大标题 | 黑字加粗居中，约 20pt，下方深灰细线，无底色 |
| 章节 / 条目标题 | 黑字加粗、左对齐，约 11pt，无底色无分隔线 |
| 独立文档块标题条 | 深灰 `595959` 通栏、白字加粗、约 15pt |
| 块页眉 | 右对齐灰字 `808080`，约 8.5pt，下方浅灰细线 |
| 共性前提通栏行 | 浅灰 `EDEDED`，左侧约 3pt 深灰竖条 |
| 表头 | 灰底 `D9D9D9`、黑字加粗、跨页重复，原则上居中 |
| 数据行 | 白色 / 浅灰 `F7F7F7` 交替 |
| WARNING 行 | 左侧红竖条；“警告：”红字加粗，正文黑字，不用红底 |
| 相同 / 共享项 | 浅蓝灰 `EAEFF3` 或“同左” |
| 边框 | 中性浅灰 `BFBFBF` |
| 正文 | Arial 等无衬线字体，约 9.5pt |
| 结尾 | study 文档居中灰字“— 笔记整理完毕 —”；速查表省略 |
