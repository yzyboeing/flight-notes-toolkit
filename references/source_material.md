# 图片型原始材料

## PDF 与截图的常见风险

- 课件导出的 PDF 可能没有文字层；文字提取为空时改用光栅化和 OCR。
- 表格型页面 OCR 后容易发生行列错位，只采用正文明确写出的数字；无法可靠转录的完整表格注明“以原件为准”，不得猜测。
- 手机长截图可能发生图层重叠或遮挡。发现内容不连贯时写 `【缺失，待原件补充】`，请用户补原件。

## 图一律转成文字

成品不插图片、截图，不重画图，不使用 ASCII 图或 Mermaid。

| 原图类型 | 转换方式 |
|---|---|
| 流程图 / 决策树 | 写成 `A → B → C`；有分支时使用时序流程表或故障处置表 |
| 思维导图 / 分类树 | 分类归组表，或换行缩进加加粗前缀标签 |
| 参数表 / 对照表图片 | 重建为表格 |
| 结构示意图 | 只转写图中明确表达的部件关系和信号流向 |
| 颜色分级图 | 把颜色转成原图对应的文字等级 |

纯装饰图直接略过，不必注明。

复杂系统原理图、位置关系图或多变量曲线在尽力转写后，如果文字表达仍明显损失信息，可在知识点末尾单独写：

```text
［原图：<图的标题或内容一句话> — 建议手动插入］
```

每篇通常不超过 2–3 处。图中看不清的部分按缺失处理，不为了写成通顺句子而添加原图没有的关系或条件。
