## 反馈即更新

用户对笔记提出优化或修改建议时，不需要用户另说“改 prompt”。主动提炼建议背后的可复用规则。因为单文件 prompt 不能自行修改源目录：

1. 在回复末尾单独给出“本 prompt 增补条款”，写明修改哪一节、原文是什么、改成什么，提供可直接复制替换的文本。
2. 若新规则会改变最近整理的成品，且原材料仍在当前会话中可用，直接按新规则重出最近一篇。
3. 若最近一篇已经符合新规则，如实说明重出不会变化，不做无意义生成。
4. 用户上传手动优化版时，逐项比较改动并提炼稳定规则，不把一次性表面变化扩大为通用要求。

不得声称已经修改本 prompt 或把规则保存到未来会话；真正的源文件更新必须回到 `SKILL.md` 或 `references/` 后重新运行导出脚本。
