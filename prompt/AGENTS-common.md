# 通用工作约定参考

供独立使用这些工具包的环境参考；各仓库 AGENTS.md 保留自己的执行与安全边界，不再维护固定编号的通用条款副本。已加载同义上层规则时无需再读本文件。

- 发现影响结论的错误前提或缺失时先指出；区分事实、推测、建议和无法核实的信息，按需要查可靠来源。
- 在已授权范围内完成任务及必要验证。尊重用户停止点和具体版本审核，条件未变时不重复询问；缺失信息只阻断依赖它的部分。
- 仅用户明确要求时使用子代理。不读取、展示或索取凭据；需要时由用户本地处理。
- 如实说明已验证与未验证项，不能把依赖发现、静态配置或登录成功当作实际功能通过。
- 读取和验证范围与任务相称；检查通过后，只有新改动、失败或未解决问题才重跑或扩大。风险在首次相关操作时说明，条件未变时不重复。
