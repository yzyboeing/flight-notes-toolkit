## 一、三条铁律

1. **宁可漏报，不可错报。** 核过没问题就记「核对无误」。编造一条（现文搜不到、手册页码对不上、排版问题成品页上不存在），所在部分整个退回重做。
2. **逐字引文 + 精确定位。** 「笔记现文」从基线逐字复制（含标点、【】、•、–），不改写、不拼接；写页码 + 条目号 + 位置；报出前用引文在基线 PDF 里回查一遍。手册依据写全：手册名、修订号、章节号、原 PDF 页码 + 一两句原文摘录（核对用；成品里不写出处）。
3. **查不到 ＝ 培训资料，不是问题（SD-94）。** 手册里找不到依据的内容默认来自公司培训课件：不删、不标注、不报「无出处」，只审逻辑和表达；台账标「手册无依据（培训资料）」。存疑只给「查到了手册但两处说法拿不准」的情况。

## 二、核对一个知识点

- **逐项核**：逻辑（条件与结果、先后、任一 / 全部、且 / 或、必须 / 建议 / 可以、适用阶段与机型）；数值与边界（数值、单位、范围端点、含不含本数）；限定条件（前提、例外、适用范围）；表达（有没有把「建议」说成「必须」、「可能」说成「会」）。
- **同一主题查全**：FCOM、FCTM、QRH、AFM、SOP、运行手册、MEL、除冰大纲、技术通告都查；检查单看全所有分支。手册之间说法不同报「手册口径不一」并列各家原文。
- **两型分开核**：737-NG、737-8 各用各的手册；不默认两型相同，也不拿一型手册说另一型错。
- **先判合并格**：读 Word 必须处理 gridSpan / vMerge；要报「空白」「错列」的先看成品页图像。
- **全书查一致**：同一数值 / 术语在全书其他位置（第 1 章原理 ↔ 第 2 章技术 ↔ 第 3 章运行 ↔ 第 4 章处置）是否一致；改一处列出全部联动位置（SD-109）。
- **自绘图也要核**：图中每个数值、两型标注与所在条目正文逐项对照（教训：1.7-6 起动时序图曾把两型 N2 标反）。

- 书内机型统一称 737-NG / 737-8。两本都不收 HUD / AIII 内容（SD-168）。
- **表述贴近原手册（SD-177）**：译名与句子尽量用 FCOM / FCTM 中文原文（其次 QRH、公司手册）；原文明显逻辑错误或过于繁琐才改写，改写不改原意、数值与条件逐字；不用手册里没有的自造说法（禁用说法见《手册用语表.json》，例：「结冰偏置」→「结冰情况的失速警告逻辑设定」）。

- **随通告更新的名单不抄进笔记**：机场 / 跑道 / 程序名单只写查询位置。

## 四、两本定位与结构

**一本成品**（SD-234，2026-10-24 用户：「之前的两个版本都只做溯源，以后只维护这个最新版这一本」）：《B737-NG / B737-8 机型理论速查笔记》，5 章 + 附录 64 节（SD-241），唯一内容真源 `notes_src/`；结构见总纲第三节。原《B737机型理论详解》《B737机型理论速查》只作溯源，`速查/速查源.md` 不再更新、不再构建单册（要出溯源对照时 `BUILD_QR=1`）。下表「速查」一列是速查单册的口径，现只在核对溯源时用；本书一条的写法按「完整版」一列。

| 维度 | 完整版 | 速查 |
|---|---|---|
| 目的 | 系统理解：原理、逻辑、程序全貌、两型差异 | 快速查数与判断：数据、限制、条件分支、门槛 |
| 组织 | 节 = FCOM 章 / 手册；条目按 N1 顺序 | 段 = 飞行流程；组 = 系统 / 主题；同一知识链的条目相邻 |
| 一条的样子 | 不限长；表 + 注 + 图 | ≤ 1 页；首行「要点」一句话；以表为主；注精简（能并回表格行的并回） |
| 程序类 | 完整步骤 | 只收门槛、分支、口令 |
| 算例 | 可写 | 「例：」注 ≤ 1 条 |
| 图 | 用户点名的图（P01） | 同完整版（完整版的图速查对应条目同收） |
| 入口 | 结构目录 + 速查目录（SD-234：按章节 8 段，逐条列出全书条目并 ↗ 交叉，排在结构目录之后；不设前言、使用说明——SD-240） | 8 段 + 按主题查（无前言、使用说明、必背清单、限制数据总表） |
| 星级 | 不标 | 不标 |

- **节内顺序 N1**：系统类——组成与原理 → 控制与正常工作 → 数据与限制 → 指示与告警 → 非正常与处置 → 技术提示；运行类——定义与概念 → 规则与标准 → 按飞行阶段的程序 → 非正常 / 特殊情况 → 案例与算例。
- **章节归属**（SD-234）：系统原理与指示 → 第 1 章（节号 = FCOM 章号）；职责、速度、性能与各阶段操纵技术 / FCTM / SOP → 第 2 章（按飞行流程）；运行手册 / 局方规章 / 气象与季节运行 → 第 3 章；外部环境与特殊情况（超速、颠簸、风切变、鸟击、冰晶、GNSS 干扰、无线电失效）的识别、预防与告警决策 → 第 4 章「特殊情况与风险」（SD-241）；系统故障处置、模拟机科目 / QRH 记忆项目与机动（含改出时序与喊话）→ 第 5 章；两型差异汇总、QRH 差异、只涉及一型的技术专题 → 附录（6.1～6.4）。
- **两本一一对应**（SD-234 起只用于核对溯源）：速查每个知识点都能在完整版找到出处（绑定写全）；两本都有的，数值、条件、结论必须一致，速查只许少收行、不许改写成不同意思；共有表以速查优化过的为准，完整版独有的行和更详细的文字保留；**速查有、完整版没有的行**：记进当期《优化意见记录》，方案默认逐行合并补进完整版（完整版是唯一内容真源），数值、机型或出处拿不准的列给用户定，不删速查那一行了事（SD-217）；改一处必须同改另一处（SD-191 / 192）。
- **速查一个知识点只写一处**（SD-234 起只用于核对溯源）：不同主题相同的知识点只留查找时第一反应的那条，另一主题在《速查按主题查》用 see 挂接；机型差异段保留汇总式重复。
- **删改两本同做**：删除前把被删一边独有的信息并到保留的一边；**删速查条目须用户确认**（SD-196）；合并后查同块有没有重复句。
- **同一本里的重复**：讲同一件事、文字大段重合的保留一处、独有信息并入；互补的（原理 ↔ 处置 ↔ 模拟机程序）不算重复。
- **速查目录**（SD-234）：每条正文在速查目录里恰好作为直接项出现一次（就是它所在的节 / 段），其他浏览路径用 ↗（`qr_directory.py` 的 DIMS / XREF）；新增节先在 DIMS 里加主题，新增条目要考虑是否在相关阶段主题里加 ↗。

## 五、补全、精简与展示

- **补全**写清补什么、补到哪里（条目 / 表行 / 表后注）、为什么重要；背景介绍、与操作判断无关的原理细节不补；大参考表不照搬，写定义与查法。
- **新增知识点先通查已有内容**：检索两本同一数值、术语、缩写、主题，列出已有位置再决定新增、并入或修改；能并入已有条目 / 表格一行的优先并入。
- **补入只逐行合并**：同表头的表补行时逐行合并，不整表替换（教训：通用表头误配丢行）；批量插条目防倒序；补完跑丢失 / 重复扫描（K-S7）。
- **精简信息无损（最重要）**：精简 / 改写前列全原文要素（数值、单位、条件、例外、机型标注、颜色），改后逐项核对，附「无损声明」。手册原句（检查单、警告、限制、定义、CAUTION / NOTE）不改写，只删重复；培训性解释、推理、导语里的拖沓句可以精简。
- **啰嗦句可删短（2026-10-21 用户，优化意见第 123 条）**：「啰嗦或者不重要的冗长的句子只要不影响基本原理和对概念的理解都可以做精简，不用都保留」——解释性铺垫、重复说法、换句话复述、编写说明、译文对照可删短或删去；数值、单位、条件、例外、机型标注、限制与程序步骤照上一条不丢。
- **不算啰嗦**：两型对照里两列相同的写法、缩写说明、安全警示的重复。
- **原理类定义不写公式**（SD-152）：用浅显的话写清含义与关系，必要时加一条「关系」注。
- **并列多条用表**（SD-173）：并列的因素、情况、条件、分支、状态写成表格；「满足以下任一条件」作表头或前提行；一句话的定义不改。
- **两型共有的概念用左右对比表**（SD-170 / 194）：排法见《排版规则总表》B13；不在格内用「【737-NG】…／【737-8】…」混写。
- **多对象比较用「对象 × 属性」矩阵表（2026-10-22 用户：火警探测和灭火系统总结「这样子整理更简洁」）**：几个部位 / 系统按同一组属性比较时，行＝对象、列＝属性（如 部位｜探测｜探测供电｜灭火｜灭火供电｜环路失效｜指示与其他），一格只写一种属性，原有信息一条不丢；两型只差一两格时格内写【机型】并登记两型混写保留（SD-194）。
- **外来总结 / 课件 / 教材内容**（截图、培训表）：逐格对两型 FCOM 核实再收——错漏、缺供电、两型不分、条件缺失（如「仅地面」）都要当场告诉用户并改正，不照搬。
- **缩写注放主场条目**（W06）：以该缩写为重点的条目注一次，顺带提到的不注；**标题、表头、首列或要点里出现、读者不一定认识的缩写（PDG / OIS / TCH / RDH / LOUT 等），该条目就是主场，必须注英文全称和中文含义**（SD-230，2026-10-23 用户）。
- **示例先写全、再解读**（SD-230，2026-10-23 用户速查第 440 / 441 条：「雪情通告示例报文不全，下面的解读没办法对照」「示例报文先写出来，下面是解读」）：报文、通告、电报、检查单示例类条目，先在前提行列出手册原文的完整报文（不写「全文从略」），再逐段解读，解读的每一段都能在原文里找到；原文有明显笔误的照改并在解读里说明。
- **展示方式**按语义判断（限制 / 数值 / 步骤 / 对比 / 因果 / 定义各有合适排法），建议改排法时列全书同类 ≥ 2 处作对照。

## 六、问题分类与级别

- **类别**：内容 / 逻辑 / 补全 / 优化 / 精简 / 展示 / 一致性 / 写法。
- **级别**：A 与手册矛盾或可能误导操作；B 不准确、不完整或逻辑有问题；C 全书不一致或删后丢信息；D 表达优化、精简、展示、写法。
- **改法**写成可直接执行的形式；精简附无损声明；联动位置列全，没有写「无」；两本位置都写（完整版 x.y 第 N 条 + 速查第 N 条）。
