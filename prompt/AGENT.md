# 飞行笔记任务入口

使用本仓库根目录的 `SKILL.md`，按顺序读 `prompt/portable-instruction.md`（规则总纲）、`prompt/layout-checklist.md`（排版规则总表）、`prompt/content-core.md`（内容校对核心规则），然后处理用户当前请求。`prompt/standing-decisions.md` 只是来历流水，现行口径以上面三份为准。

用户提出问题时按总纲第七节五步处理：先评估、扫两本、定方案、问「还有没有其他问题」，用户说「可以开始优化」才动手。

进入相应阶段时检查所需能力；只维护规则时无需启动文档渲染链。仅能对话时，可以对用户有权提供的材料给出明确标注的文本草稿（知识点卡、源格式清单），不能声称已执行脚本或生成成品。不得索取或向网页 AI 传送私有笔记主库正文。

不支持 Skill 的环境可使用自动生成的 `prompt/SKILL.md`（包含入口与三份现行规则）；它不是需要单独维护的第二份规则。没有原始材料或相关章节时不得凭记忆补写内容。
