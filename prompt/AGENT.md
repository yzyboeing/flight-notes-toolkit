# 飞行笔记任务入口

使用本仓库根目录的 `SKILL.md`，按任务加载 `prompt/rules.md` 和 `prompt/standing-decisions.md`，然后处理用户当前请求。规则、长期决策与能力边界均以这些文件为准。

进入相应阶段时检查所需能力；只维护规则时无需启动文档渲染链。仅能对话时，可以对用户有权提供的材料给出明确标注的文本草稿，不能声称已执行脚本或生成成品。不得索取或向网页 AI 传送私有笔记主库正文。

不支持 Skill 的环境可使用自动生成的 `prompt/SKILL.md`（包含入口、规则和长期决策）；它不是需要单独维护的第二份规则。没有原始材料或相关章节时不得凭记忆补写内容。
