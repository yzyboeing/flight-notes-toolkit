# 飞行笔记任务入口

使用本仓库根目录的 `SKILL.md`。项目现行规则只有私有笔记库 `规则/现行规则.md` 一份（2026-11-20 规则瘦身），读完再处理用户当前请求；`prompt/archive/` 里的旧规则与 SD-1～266 只查来历。

用户提出问题时按现行规则第一节处理：先评估、扫全书同类、定方案、问「还有没有其他问题」，用户说「开始」才动手。

进入相应阶段时检查所需能力；只维护规则时无需启动文档渲染链。仅能对话时，可以对用户有权提供的材料给出明确标注的文本草稿（知识点卡、源格式清单），不能声称已执行脚本或生成成品。不得索取或向网页 AI 传送私有笔记主库正文。没有原始材料或相关章节时不得凭记忆补写内容。
