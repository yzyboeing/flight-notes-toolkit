## 怎么用（任何 AI 通用）

1. 改完笔记或工具链后先出成品：`cd ~/flight-repos/gh-private && DOC_EDITION=<版本名> ./sync.sh --full "说明"`（约 40 分钟），sync 自动跑全部检查器，报告在 `build/排版检查报告.md`（含 K-B5 留白页、K-Z3 过度压缩）、`build/两本同表对照报告.md`、`build/联动检查报告.md`；交付前再跑 `table_diff.py` 与上一个用户满意版逐表比对（总纲第九节）。
2. 单独跑：`python3 ~/flight-repos/pub/tools/check_layout.py --repo ~/flight-repos/gh-private --out build/排版检查报告.md`；`check_struct.py`、`check_src.py`、`check_pair.py`、`check_userpins.py` 同目录。
3. 按报告处理：**错误**必须改到 0（用户定下的规则一律错误级，新增例外前先对照用户原话）；**新建议**逐条打开成品页看，裁定「改」或「不改 + 理由」写进 `gh-private/排版建议裁定.json`（裁定过的只计数；内容变了签名变、自动重出）。
4. 人工或外部 AI 校对时逐条对照成品页，每条问题写页码、条目号、表头和规则编号。
5. 内容核对规则见 `content-core.md`；工作流程、出基线清单见 `portable-instruction.md`（规则总纲）。

## B　表格（对齐、加点、结构、列宽、分页）

| 编号 | 规则 | 执行 |
|---|---|---|
| **B01** | **表头与首列**：表头一律居中、加粗。首列一律居中、加粗（父子层级格按悬挂缩进左齐）。例外：首列与其他列同为并列数据的对比表（液压分配表），首列不加粗、整表居中。 | 自动 |
| **B02** | **取值与短语居中、不加点（SD-103）**：数值、带单位的值、短值、短语，以及每格都是约 20 字以内无句读短话或顿号列举的列，整列居中不加点；表头为「时机 / 宣布时机 / 总则 / 类别」的列整列居中；「—」占位一律居中；所有格纵向居中。 | 自动 / K-T3 |
| **B03** | **句子列整列加点（SD-102 / 127 / 215 / 219）**：非首列里有长句（≥ 15 字，短括注不计）的列 → 整列左对齐、每格加「•」，一格只有一句也加，**不论表头叫什么**；三列及以上表里整列每格只有一项的非机型列例外，按 B38 居中（SD-219）；同列统一（取值短值格和 ①② 步骤格除外）；序号表除外（B05）；用户点名的列照源文件标注（G4）。 | 自动 / K-T6、K-T11、K-USERPIN |
| **B04** | **居中为默认（SD-129～135）**：加点的列靠左；不加点的数据格一律居中。例外靠左：显式 `col-left`、序号表其余列、父子层级格、一格内 ≥ 2 条编号项且含长句的步骤说明。并列清单表标 `parallel`，首列不加粗。 | 自动 |
| **B05** | **序号表（SD-140 / 158 / 207，错误级）**：只用于序号列右边只有一列内容的表（「序号 ｜ 内容」「类别 ｜ 序号 ｜ 条件」）——其余列一律左对齐、不加「•」，子项「–」保留；序号列右边有两列以上内容的表按普通列规则。「10、15、25」这类数值首列不算序号；末尾允许 1～2 行非编号补充行。**步骤表**：首列是序号 / 步骤 / # 且表示先后步骤、后面是「步骤本身 + 说明 / 核实 / 细节」的表——第一列圈码；第二列（操作 / 动作 / 判断）整列居中不加点；第三列起说明类靠左加点、取值类居中；源文件显式标 `col-center` / `col-bullet`。不适用：两型对照的序号表（B10 ①）、序号后两列同类并列（PF ｜ PM，B17）。 | 自动 / K-T12（错误） |
| **B06** | **父子层级（SD-180 / 182 / 191）**：父项（总括 / 引语，常以「：」结尾）深蓝加粗；同一格另有「•」并列条目时父项也加「•」，单独引出分项或带编号的父项不加；子项「– 子项」缩进一级、折行对齐文字；子项有 ①② 编号时不加短线；父项下只有一个子项时合成一行；整格每段「- 」开头的是并列列表，排「•」。小标题段：一格各项都是粗体「小标题：内容」且整列无其他加点格时不加点。段首「– -」双短横、原样「- 」报错。 | 自动 / K-T10 |
| **B07** | **格内分条门槛**：一格内 ≥ 2 个各自独立的判断 / 条件 / 动作才分条；短状态、标签、带因果 / 转折的连续叙述不分条；整格约 35 字以上才按「；」拆。①②③ 只给真正的时序步骤；并列备选条件不编号；「① … → ② …」箭头顺序链保持一行。 | 自动 / K-T4 |
