# 长期决策记录

本文件保存**跨文档长期有效**的用户决策，与只约束单次任务的答复不同——这里的条目对以后每一次整理都生效。

**每次整理前必读。** 优先级：`rules.md` 第二节内容忠实硬约束 > **本文件** > `rules.md` 其余各节。

- **已在本文件有结论的问题，不得重复提问。**
- 条目只记录**决策**，不记录某一份材料的技术事实、数值或程序。
- 只有用户明确表示某项选择跨文档持续生效时才写入；单次答复不自动升级为长期决策。
- 用户改变决策时更新原条目并改日期，被推翻的条目移入文末「历史决策」，不删除。

## SD-64 红蓝分工定稿（2026-09-29 用户「按最优方案处理」）

**规则：红＝禁令与强制要求（文字性警示）；蓝＝数值（要背的）。**

- 为什么不按「限制 → 红」：本书绝大多数内容本身就是限制，凡限制皆红等于全书皆红，红色就失去警示力。数值是要背的，不是要警惕的。
- 判定在渲染器里做，不改源文件标记，因此全书口径天然一致、可随时回退：
  - `<em>` 内含禁令词（`不得|禁止|严禁|不要|必须|不能|不可|只能|立即|切勿|不准|务必`）且 ≤ 16 字 → **红 `C00000`**；
  - `<em>` 内不含禁令词但含数字且 ≤ 20 字 → **蓝 `1F4E79`**；
  - 其余 → 黑色加粗；`<small>` 解释段内一律灰，不着色。
- `<b>…</b>`（SD-63 新增标记）＝要背的数值，同样渲染为蓝。本轮用脚本对全库表格做**只增不减**的补标：仅处理「非首列、整格无任何标记、内容为纯数值（可带单位）」的单元格，共 17 个文件 170 处；机型串（`737-8` 等）已排除。
- 注解条由三色收敛为两色：**警示＝红**，**注解与前提＝蓝**（前提条的琥珀 `FBF2E3` / `BF8F00` 停用）。
- 效果核查（竖版 349 页）：红色 run 由 2102 降至 354（约每页 1 处），蓝色由 16 升至 2045。红色片段抽样 288 种，全部为「禁止 / 不得 / 不要 / 立即 / 必须」类，无误用。
- **未做**：数值列小数点对齐与等宽数字。现有数值多为等位整数，居中已足够整齐，改为 DECIMAL 制表位需逐格改动、风险大于收益，暂不做。
